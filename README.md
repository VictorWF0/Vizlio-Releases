# Vizlio

> Captura de tela profissional para Windows — rápido, limpo e sem distrações.

**Vizlio by JVC** · Windows 11 · 64-bit

## Download

👉 [Baixar Vizlio-Setup-1.3.0.exe](../../releases/latest)

## Funcionalidades

- Captura de região seletiva com overlay interativo
- Suporte a múltiplos monitores simultaneamente
- Crosshair adaptativo — visível em qualquer cor de fundo
- Ferramentas de anotação: Retângulo, Seta, Lápis, Texto
- Interface nítida em qualquer escala (100% a 225%)
- Toast Notifications nativas do Windows
- Atalhos globais configuráveis
- Temas Claro / Escuro
- Idiomas: PT-BR, EN, ES

## Requisitos

- Windows 10 (1809+) ou Windows 11
- 64-bit
- ~79 MB de espaço em disco

## Instalação

1. Baixe o instalador abaixo
2. Execute `Vizlio-Setup-1.3.0.exe`
3. Siga o assistente de instalação
4. O Vizlio iniciará automaticamente na bandeja do sistema
